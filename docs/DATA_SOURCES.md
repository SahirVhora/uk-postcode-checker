# Area Pack data sources

Every dataset is official open data or a public API. No paid or terms-restricted property sites are used, scraped or referenced. Each run records the source URL, licence, fetch time, row count and status in the `source_runs` table (see `python -m pipeline.validate`).

File names, dataset IDs and download links are discovered at run time from the landing pages below. If a page no longer looks as expected the source stops with `failed_format_changed` and a message saying what was expected and what was found.

Suggested refresh cadence: monthly, `python -m pipeline.run --sources all --refresh` then `python -m pipeline.export`.

## Known caveats

* **Distances** are straight lines from the postcode centroid to the gate: a postcode-centroid estimate, the council's LLPG distance for a specific address may differ by up to about 0.1 mile.
* **Catchment flags** are a point-in-polygon test of the postcode centroid. A postcode that straddles a boundary can have addresses on both sides. Always check the exact address on the council map. Ten sample postcodes were checked against the council's own server-side query and all matched.
* **Overlapping catchments**: the council publishes shared zones as duplicate features (for example an area in both the Tudor Grange and Light Hall catchments). Features are unioned per school and a postcode can be in more than one catchment.
* **Admissions figures disagree between documents.** The offer-day table and the catchment map panels give different figures for 2025 (TGA 0.14 mi vs 0.315 mi; Alderbrook 'Sibling (Out of Catchment) 3.75 mi' vs 'Priority 6 Distance 0.405 mi'). The maps may reflect places offered after waiting-list movement, but they do not say so. Indicators use the offer-day table; both are shown. Listed in MANUAL_CHECKS.md.
* **Admission category labels** on older documents use the priority numbering of that year's policy. History is matched by label text (`Distance`, `Catchment`, `Sibling`), not by number. See `history_label_aliases` in each rules file.
* **Crime locations** are anonymised by the police (snapped to nearby map points) and the API has no LSOA field, so LSOA assignment uses point-in-polygon. A one-month check for LSOA E01010203 using the LSOA polygon as the API search area returned the same count (61 = 61). LSOAs containing shopping areas have very high all-crime rates driven by shoplifting; scoring uses the family-relevant rate (burglary, vehicle crime, violence and sexual offences, robbery).
* **Ofsted**: overall effectiveness has not been graded since September 2024 (shown as published, often 'Not judged'). Report cards started in November 2025.
* **EPC to PPD matching** (`pipeline/matching.py`): same postcode; normalised address (case, punctuation, common abbreviations, flat/apartment prefixes); `exact` when the SAON+PAON number part equals the EPC address before the street name, otherwise `tokens` when every PPD number and street token appears and the EPC has no extra house number. Newest certificate wins. The match rate is printed by `python -m pipeline.validate`.
* **Bedrooms**: EPCs record habitable rooms, not bedrooms. '4-bed-equivalent' means 5 or more habitable rooms and is labelled as an estimate.
* **Prices** use the latest sale date in the data as the reference point for 'last 24 months', so results are reproducible offline.
